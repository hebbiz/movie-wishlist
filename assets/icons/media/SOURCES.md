# Media icon sources

- Service marks: Simple Icons and the respective official brand/media resources.
- Ultra HD Blu-ray and Blu-ray Disc marks: Blu-ray Disc Association geometry.
- DVD-Video mark: DVD Format / Logo Licensing Company geometry.
- Neutral UI icons: Tabler Icons v3.47.0.

All working SVGs are monochrome and inherit the chip color through `currentColor` or a CSS mask. Brand and format marks may remain protected trademarks; use them only to identify the corresponding services and official media formats.
